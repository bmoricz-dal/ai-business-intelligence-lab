# Website finishing plan

The published Workers site already has a clear five-report structure and a
strong light-blue visual direction. The final pass should focus on:

1. Replace prototype and owner-review wording with an accurate public status.
2. Add prominent links to the Data and Methods Guide and GitHub repository in
   the Method section and footer.
3. Give Reports 4 and 5 the same visual prominence and chart treatment as the
   first three reports.
4. Turn dropdown headings into fully keyboard-operable controls with clear
   expanded and collapsed states.
5. Add a short "How to read the evidence" box beside each denominator.
6. Add publication dates, version labels and a visible last-updated date.
7. Check every PDF download, official-source link and future GitHub link.
8. Run mobile checks at narrow, medium and desktop widths.
9. Run keyboard, focus-order, colour-contrast and screen-reader checks.
10. Add basic metadata: page description, social image, canonical URL and
    descriptive report titles.
11. Keep future sector and adoption-pathway pages labelled as planned until
    their evidence has passed the same checks.
12. Complete a final wording review so no descriptive result reads as causal or
    statistically significant.
