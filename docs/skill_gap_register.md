# Skill-gap register

This register records capabilities that could limit evidence quality or delivery. It is not a claim that the project currently possesses each capability.

| ID | Capability gap | Why it matters | Current response | Next test |
|---|---|---|---|---|
| SG-001 | Construction tender-domain review | Synthetic workflow boundaries need practitioner validation | Keep pricing, safety, method statements, programmes and commitments outside autonomous output | Ask an experienced estimator or bid manager to review the six workstations |
| SG-002 | Independent SME benefit evaluation | Published construction cases do not establish UK SME ROI | Label technical, perceived, qualitative and self-reported outcomes separately | Pre-register a local baseline and pilot if a partner is approved |
| SG-003 | Sector-by-size estimation | UKBDS construction estimates are not SME-only | Retain the all-size denominator, bases and confidence intervals | Monitor official releases or commission representative primary research |
| SG-004 | Construction accessibility testing | Automated checks cannot replace user testing | Use semantic controls, keyboard-operable inputs and visible status text | Run keyboard, screen-reader and zoom testing before publication |
| SG-005 | Cloudflare production verification | A local build does not prove live routing and asset delivery | Keep deployment blocked until owner approval | Deploy once, then verify every route and CSV on the public Worker |
